BEFORE YOU START

先分清：手机入口 ≠ 说明书The guide and the app are different

你正在看的远端网页只负责讲解，不能直接访问你的 Mac。小冰聊天入口是 Mac 提供的 HTTPS 局域网地址；安装到主屏幕后，聊天和工具仍由 Mac 执行。This hosted page only explains the steps. It cannot access your Mac. The actual app uses your Mac's HTTPS LAN address; after Home Screen installation, the Mac still executes chats and tools.
现在可以怎样使用Supported now

Mac 保持开机，手机和 Mac 连接同一 Wi-Fi，打开小冰的加密地址。网页 App 可以放进 iPhone 主屏幕。Keep your Mac awake, connect both devices to the same Wi-Fi and use the app's HTTPS address. Add it to your iPhone Home Screen.

当前仍有这些边界Current limits

尚未部署外网或蜂窝访问，也不是 App Store 安装包。iPhone 真机安装、软键盘和实际 Wi-Fi 连通仍待你验证。Internet and cellular access are not deployed. This is not an App Store package. Installation, the keyboard and connectivity still need verification on your iPhone.

01 / ONE-TIME SETUP

第一次使用，按顺序做这五步First time? Follow these five steps

先完成证书设置，再生成登录链接。链接只有 60 秒有效，过期重新生成即可，不用重装证书。Set up the certificate before creating a login link. Each link lasts 60 seconds; if it expires, create a new one without reinstalling the certificate.

已勾选 0 / 5 步

勾选只记录你的操作进度，不代表页面已检测到设备或连接成功。Checks track your own progress; they do not verify a device or connection.

01
Mac + iPhone

让两台设备连接同一 Wi-FiConnect both devices to the same Wi-Fi

  1. Mac 保持开机，打开“小冰助手”。Keep your Mac awake and open Xiaobing.
  2. iPhone 在“设置 → Wi-Fi”中选择和 Mac 相同的网络。On your iPhone, choose the same Wi-Fi network as your Mac.
  3. 手机入口还需要 Mac 的 HTTPS 网关在线；若重启过 Mac，先看本页“重启与命令”。The Mac's HTTPS gateway must also be running. After a Mac restart, see Restart & commands below.
完成标志：两台设备在同一网络，Mac 没有休眠。Done when both devices share a network and the Mac is awake.
02
Mac → iPhone

把证书 AirDrop 到自己的 iPhoneAirDrop the certificate to your iPhone

在 Mac 的 Finder 找到 xiaobing-root-ca.cer，右键“共享 → AirDrop”，选择自己的 iPhone；手机点接收。In Finder, select xiaobing-root-ca.cer, choose Share → AirDrop and select your iPhone. Accept it on the phone.

文件位置：File location:
~/.local/share/xiaobing-assistant/mobile/xiaobing-root-ca.cer

Finder 里找不到？复制这条命令Can't find it? Use this command
Mac Terminal
open -R "$HOME/.local/share/xiaobing-assistant/mobile/xiaobing-root-ca.cer"
只发送这个 .cer 文件。它用于让 iPhone 识别你的 Mac；不要发送同目录里的 .key 私钥。Send only the .cer file, which lets the iPhone recognize your Mac. Do not share the .key private keys in the same folder.
03
iPhone

安装证书，再开启“完全信任”Install the certificate, then enable full trust

  1. 打开“设置 → 通用 → VPN 与设备管理”，找到刚收到的证书描述文件，按系统提示安装。Open Settings → General → VPN & Device Management. Find the certificate profile and follow the installation prompts.
  2. 继续打开“设置 → 通用 → 关于本机 → 证书信任设置”。Then open Settings → General → About → Certificate Trust Settings.
  3. 找到 Xiaobing Local Mobile CA，开启“完全信任”。Enable full trust for Xiaobing Local Mobile CA.

04
Mac → Safari

生成登录链接，60 秒内在手机打开Create a login link and open it within 60 seconds

  1. Mac 的“应用程序”里双击 小冰手机登录.command。它会把一次性登录链接复制到 Mac 剪贴板。In your Mac's Applications folder, double-click 小冰手机登录.command. It copies a one-time login link to the Mac clipboard.
  2. 把这个完整链接传到自己的 iPhone，用 Safari 打开。如果两台设备已配置 Apple“通用剪贴板”，可直接粘贴；否则使用你自己的传递方式。Transfer the complete link to your iPhone and open it in Safari. If you already use Apple's Universal Clipboard, paste it directly; otherwise use your own transfer method.
  3. 如果出现小冰登录框，也可以把完整链接粘贴进“访问凭据或一次性登录链接”，然后点登录。If Xiaobing shows a login screen, paste the complete link into “Access credential or one-time login link” and sign in.
在 Mac 打开登录快捷方式Open the Mac login shortcut
open "$HOME/Applications/小冰手机登录.command"
完成标志：Safari 显示小冰聊天界面，而不是登录框或证书警告。Done when Safari shows the chat interface, without a login screen or certificate warning.

链接一次使用、60 秒有效。过期或已使用，重新双击生成即可。不要把登录链接粘贴到本说明网页。Links are single-use and expire after 60 seconds. Generate a new one if needed. Do not paste login links into this guide.

05
Safari → Home Screen

添加到主屏幕，以后像 App 一样打开Add to your Home Screen and launch like an app

  1. 在 Safari 的小冰页面点“分享”；如果分享入口在“更多”菜单里，先展开菜单。On the Xiaobing page in Safari, open Share. Expand the More menu first if needed.
  2. 选择“添加到主屏幕”；找不到时可在分享操作列表中编辑/添加该操作。Choose Add to Home Screen. If it is missing, edit the actions in the Share sheet.
  3. 如果出现“作为网页 App 打开”，保持开启，再点“添加”。If Open as Web App is shown, leave it enabled and tap Add.
  4. 回到主屏幕，点“冰”图标打开。如果独立窗口再次要求登录，生成并粘贴一条新的登录链接。Tap the ice-character icon on your Home Screen. If the app asks you to sign in again, create and paste a fresh login link.

04 / WHEN SOMETHING GETS STUCK

碰到问题，先按现象查Troubleshoot by what you see

“连接不是私密连接” / 证书不受信任“Your connection is not private” / Untrusted certificate

先检查证书是否同时完成了“安装”和“完全信任”。确认信任的是本机生成的 Xiaobing Local Mobile CA。如果 Mac 地址变过，也需要核对当前地址和服务证书。不要用忽略证书错误代替配置。Check that you both installed the certificate and enabled full trust for your Mac's Xiaobing Local Mobile CA. If the Mac address changed, check the current address and server certificate. Do not bypass certificate errors as a substitute.

返回证书步骤 ↑Back to certificate steps ↑
Safari 一直打不开，或提示无法连接服务器Safari cannot reach the server

检查：Mac 是否休眠；后台及 HTTPS 网关是否在线；手机是否还在同一 Wi-Fi；是否用了旧地址。访客 Wi-Fi 或无线隔离也可能阻止设备互访，不能仅凭打不开判断程序故障。Check that the Mac is awake, both services are running, the phone is on the same Wi-Fi and the address is current. Guest Wi-Fi or client isolation can also block connections; an unreachable page alone does not identify an app defect.

查看状态与启动命令 ↓See status and startup commands ↓
登录链接过期、已使用，或主屏幕 App 再次要求登录Expired/used link, or Home Screen app asks to sign in again

重新在 Mac 双击“小冰手机登录.command”，使用新链接；必要时粘贴进 App 登录框。链接只有一次使用机会、60 秒有效，不需要重新装证书。Run the Mac login shortcut again and use the fresh link, pasting it into the app login form if needed. Links are single-use and valid for 60 seconds. You do not need to reinstall the certificate.

“某会话正在被其他 Codex 客户端使用”“This session is in use by another Codex client”

原会话的写入权已有其他客户端占用，小冰暂时无法接管。任务已经结束也可能仍有客户端持有写入权。先使用原窗口，等原写入者释放后再连接；界面没有可靠信息时不会猜测具体是谁，也不会强行清锁。Another client owns the original session's writer, so Xiaobing cannot attach yet. Ownership may persist after a task finishes. Use the original client and reconnect after it releases ownership. Xiaobing does not guess the owner's identity or force-clear the lock.

想在公司外面、4G/5G 下使用Use it outside your Wi-Fi or on cellular

当前交付只配置同 Wi-Fi。蜂窝网络和外网入口尚未部署。能打开本使用指南，不代表你的 Mac 已经可以从互联网访问。The current setup is for the same Wi-Fi only. Cellular and internet access are not deployed. Being able to open this guide does not make your Mac internet-accessible.

Mac 重启后，手机就打不开了It stopped working after restarting the Mac

需要重新启动小冰后台和独立 HTTPS 网关；Wi-Fi 地址变化时，还要重新生成服务证书。已有根证书通常复用，但应按当前状态核对。下面保留完整命令。Restart Xiaobing's backend and the separate HTTPS gateway. If the Wi-Fi address changed, generate a new server certificate. The root certificate is normally reused; check the current setup. Full commands are below.

06 / RECOVERY & COMMANDS

需要重启或换机时，再看这里Commands for restarts and new installations

首次安装已完成时，不用每次重跑这些命令。以下在 Mac 的项目目录中执行；手机不需要安装 Node 或开发工具。Do not rerun setup every day. Run these commands in the project directory on your Mac. Your iPhone does not need Node or developer tools.

项目目录：Model_test/小冰助手Project directory: Model_test/小冰助手
node bin/xb.mjs start
npm run mobile -- status
npm run mobile -- serve

serve 保持运行，不要关这个终端；如果网关已经在线，不要重复启动。后台关闭或 Mac 休眠都会影响手机连接。Keep serve running and its terminal open. Do not start a second gateway if one is already online. Stopping services or sleeping the Mac affects mobile access.

另一个终端：生成新登录链接Another terminal: create a fresh login link
npm run mobile -- link
换机或 Wi-Fi 地址变化：证书准备命令New Mac or changed Wi-Fi address: prepare certificates

先停止旧网关。prepare 自动从本机私网地址选择；多网卡时应显式指定 Wi-Fi IPv4。新 Mac 的根证书也需要在 iPhone 上重新安装信任。Stop the old gateway first. prepare selects a local private address; specify your Wi-Fi IPv4 if there are multiple interfaces. A new Mac also needs its new root certificate installed and trusted on the phone.

Mac Terminal
npm run mobile -- prepare
npm run mobile -- serve

停止前台网关用 Ctrl + C。这只关闭手机接入，不会停止原 Codex 会话。Use Ctrl + C to stop a foreground gateway. This stops mobile access, not the original Codex sessions.
